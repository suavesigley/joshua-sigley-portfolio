PROJECT 04 · SECURITY AUDIT

Security Controls & Compliance Audit

A simulated security audit of Botium Toys evaluating security controls, organizational risk and compliance gaps across PCI DSS, GDPR and SOC 2.

Security Audit Risk Assessment GRC PCI DSS GDPR SOC 2

Project Overview

This project involved conducting a simulated security audit of Botium Toys to evaluate its existing security controls and identify areas of risk.

The assessment focused on administrative, technical and physical security controls, followed by a review of relevant compliance requirements and the development of prioritized security recommendations.

The assessment followed a structured process:

  • Assess existing security controls
  • Identify control gaps
  • Categorize associated risks
  • Assess compliance gaps
  • Develop prioritized remediation recommendations

Controls Assessment

The controls assessment evaluated the implementation status and associated risk of key administrative, technical and physical security controls.

High-Risk Control Gaps

  • Least Privilege — Not implemented
  • Disaster Recovery Plan — Not implemented
  • Intrusion Detection System — Not implemented
  • Encryption — Not implemented
  • Password Manager — Not implemented

Medium-Risk Control Gaps

  • Separation of Duties — Not implemented
  • Legacy System Monitoring — Not implemented
  • CCTV — Not implemented

Existing Controls

  • Password Policies — Implemented
  • Firewall — Implemented
  • Backups — Implemented
  • Antivirus Software — Implemented
  • Physical Locks — Implemented
  • Fire Protection — Implemented

Risk Assessment

Identified control weaknesses were categorized according to their potential security and business impact.

High Risk

  • No encryption for sensitive data
  • No intrusion detection monitoring
  • No least-privilege access
  • No password management system

Medium Risk

  • No separation of duties
  • No CCTV monitoring
  • No legacy system monitoring

Low Risk

  • Firewall implemented
  • Backups configured
  • Antivirus installed
  • Physical locks in place

The identified risks could contribute to data breaches, unauthorized access, compliance violations and operational downtime.

Compliance Gap Assessment

The audit also assessed selected security requirements associated with PCI DSS, GDPR and SOC 2 to identify areas where existing controls did not meet the assessed requirements.

PCI DSS

  • Authorized credit card access — Not implemented
  • Secure processing environment — Not implemented
  • Encryption — Not implemented
  • Secure password policies — Not implemented

GDPR

  • EU data protection — Not implemented
  • 72-hour breach notification — Not implemented
  • Data classification — Not implemented
  • Privacy policy enforcement — Not implemented

SOC 2

  • Access policies — Not implemented
  • Data confidentiality — Not implemented
  • Data integrity — Not implemented
  • Data availability — Implemented

These findings represent a compliance gap assessment rather than a formal certification or regulatory audit.

Prioritized Recommendations

Remediation recommendations were prioritized according to risk severity and potential business impact.

01 — Implement Encryption

Sensitive data, including customer and payment information, should be protected both at rest and in transit using appropriate encryption controls.

02 — Apply Least Privilege

User access should be restricted to the systems and data required for each role. Role-based access control should be implemented to reduce unauthorized access and insider-threat risk.

03 — Deploy IDS Monitoring

An intrusion detection system should be introduced to monitor network activity and alert administrators to suspicious behaviour or potential attacks.

04 — Implement Password Management

A centralized password management system should be introduced to improve credential security, reduce password reuse and securely manage credentials.

05 — Establish Disaster Recovery

A disaster recovery plan should define backup restoration procedures, recovery priorities and recovery objectives to support business continuity.

Additional Improvements

  • Implement separation of duties
  • Improve legacy system monitoring
  • Strengthen password policies
  • Improve physical security monitoring
  • Address identified PCI DSS, GDPR and SOC 2 gaps

Expected Risk Reduction

Implementing the recommended controls would strengthen Botium Toys' overall security posture and reduce the likelihood and impact of common security risks.

  • Reduced risk of data breaches
  • Stronger access control
  • Improved threat detection
  • Improved protection of customer data
  • Improved business continuity
  • Improved compliance posture
